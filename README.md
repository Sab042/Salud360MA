# SALUD360 - Plataforma de Gestión Médica Integrada

## Descripción del Producto
SALUD360 es una aplicación integral diseñada para simplificar y optimizar la atención en salud. Permite a los pacientes agendar citas médicas, consultar su historia clínica, revisar el historial de visitas y gestionar solicitudes de medicamentos de manera eficiente.
